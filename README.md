# Genie Map Collections (MVP)

Рабочее пространство для взыскания просроченной задолженности по регулярным счетам.

## Запуск
Откройте `index.html` в браузере. Сборка и сервер не нужны. Состояние демо хранится в localStorage браузера; «Сбросить демо» возвращает исходные данные.

`sh build.sh` собирает автономный файл `dist/collections.html` (всё внутри одного HTML) для публикации.

## Что внутри
- `data.js` — демо-данные: 26 B2B-клиентов, ежемесячные счета, сигналы из биллинга / CRM / поддержки.
- `engine.js` — правила: причина неоплаты (с доказательствами и уверенностью), приоритет 0–100, рекомендованное действие, шаблоны писем, автосценарии по причине.
- `app.js` — интерфейс: очередь, карточка клиента, задачи, журнал коммуникаций, аналитика, сценарии; симуляция «Следующий день».
- `styles.css` — стили, светлая и тёмная темы.

## Ограничения MVP
- Нет реального биллинга: данные сгенерированы.
- Письма и звонки не отправляются, а записываются в журнал.
- Классификация причин на правилах, без ML.
